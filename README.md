# Kérdezéstechnika – Kommunikáció

Gyakorlati feladat a kérdezéstechnika módszereinek elsajátításához és önálló használatához.

A projekt tartalmazza:
- magyar, történelem, matematika és szakmai tantárgy kérdés-válasz példáit;
- a kommunikáció tényezőinek folyamatábráját;
- a kommunikációs funkciók gyakorlati alkalmazását;
- a leggyakoribb kommunikációs hibák rövid összefoglalását.

A weboldal az `index.html` megnyitásával használható.
